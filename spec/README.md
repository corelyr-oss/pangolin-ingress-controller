# Specifications

This directory contains specification documents for the Pangolin Ingress Controller.

## Structure

- **features/** - Feature specifications describing new functionality to be implemented
- **bugs/** - Bug specifications documenting defects and their expected resolution

## Naming Convention

Files follow the pattern: `NNNN-short-description.md` where `NNNN` is a zero-padded sequence number.

## Creating Specs

Use the Devin skill to generate a new spec document:

```
/spec feature <short description>
/spec bug <short description>
```
